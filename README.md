##  About the Project
**NekoWiki** serves as the central knowledge base and documentation repository for the **NekoCafé** website. Its purpose is to clearly document the site's visual concept, WordPress & SQL configuration, template analysis, implemented features, and final testing.

---

##  Documentation Contents
The wiki is structured into six main chapters:

* **1. Introduction:** Site theme (*Coffee Shop*), project objectives, and target audience.
* **2. Initial Configuration:** SQL and WordPress setup, plus website editing workflows.
* **3. Template Analysis:** Comparative review of the *Flat* and *Varicolored* DokuWiki templates.
* **4. Features & Plugins:** Overview of the main content structure and core functionalities.
* **5. Conclusion:** Website publication, testing logs, WordPress trivia, and final conclusions.
* **6. Contacts:** Contact information and team details.

---

## Technologies Used
